## 🌐 Accessing Swagger UI

When the application is running locally, the interactive Swagger UI is available at:

```
http://localhost:8080/swagger-ui/index.html
```

The raw OpenAPI 3.1 specification in JSON format is available at:

```
http://localhost:8080/v3/api-docs
```

Both URLs are protected with **HTTP Basic Authentication**. Use the credentials configured in `application-dev.properties`:

```properties
swagger.admin.username=admin
swagger.admin.password=admin
```

When your browser prompts for a username and password, enter the values above. In Swagger UI itself, click the **Authorize 🔒** button (top right) and enter the same credentials to enable the **Try it out** feature for all endpoints.

## 📐 API Overview

The API is organised into two tag groups visible in the Swagger UI:

### 🤖 Model
Endpoints for managing the Naive Bayes model lifecycle and monitoring the active-learning cycle.

| Method | Path | Summary |
|--------|------|---------|
| `POST` | `/api/model/train` | Trigger a manual training run |
| `GET` | `/api/model/stats` | Get model health statistics |
| `GET` | `/api/model/active-learning-status` | Get active-learning cycle status |

### 📝 Reviews
Endpoints for submitting reviews for classification, managing labelled samples, and providing human feedback.

| Method | Path | Summary |
|--------|------|---------|
| `POST` | `/api/reviews` | Submit a review for classification |
| `GET` | `/api/reviews` | List all review samples |
| `GET` | `/api/reviews/{id}` | Get a review sample by ID |
| `GET` | `/api/reviews/labelled` | List labelled review samples |
| `GET` | `/api/reviews/unlabelled` | List unlabelled review samples |
| `PATCH` | `/api/reviews/{id}/label` | Manually assign a sentiment label |
| `POST` | `/api/reviews/{id}/feedback` | Submit a prediction correction |

---

## 🔐 Security

All endpoints use **HTTP Basic Authentication** (`basicAuth`). In production, credentials are supplied via environment variables:

```
SWAGGER_USERNAME=<your-username>
SWAGGER_PASSWORD=<your-password>
```

In Swagger UI, click **Authorize 🔒**, enter your credentials, and click **Authorize** to unlock the **Try it out** button on all endpoints.

## 📦 Request & Response Schemas

All schemas are documented in the **Schemas** section at the bottom of the Swagger UI. Below is a summary of each:

### Request Schemas

#### `ReviewRequest`
Submitted when posting a new review for classification.

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| `reviewText` | string | ✅ | Max 5000 characters, not blank | The raw movie review text to classify |

#### `LabelRequest`
Submitted when manually assigning a label to a review.

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| `label` | enum | ✅ | `POSITIVE` or `NEGATIVE` | The sentiment label to assign |

#### `PredictionFeedbackRequest`
Submitted when correcting a wrong model prediction.

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| `correctedLabel` | enum | ✅ | `POSITIVE` or `NEGATIVE` | The correct label as determined by the human operator |
| `feedbackNote` | string | ❌ | Max 500 characters | Optional note explaining why the model was wrong. Logged for diagnostics, not persisted. |

#### `TrainingRequest`
Submitted when triggering a manual training run. An empty body is accepted — all fields have defaults.

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `forceRetrain` | boolean | ❌ | `false` | Bypass the minimum sample threshold and force training immediately |
| `note` | string | ❌ | `null` | Audit note logged with the training run |

### Response Schemas

#### `ReviewSampleResponse`
Returned by all review retrieval and labelling endpoints.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | integer | ❌ | Unique database identifier |
| `reviewText` | string | ❌ | The raw review text |
| `label` | enum | ✅ | `POSITIVE`, `NEGATIVE`, or `null` if not yet labelled |
| `labelSource` | enum | ✅ | `SEED`, `MANUAL`, `CLAUDE`, or `null` if not yet labelled |
| `createdAt` | datetime | ❌ | When the review was first submitted. System-managed. |
| `updatedAt` | datetime | ❌ | When the review was last updated. System-managed. |

#### `ClassifyResponse`
Returned by `POST /api/reviews`. Extends `ReviewSampleResponse` with classification metadata.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | integer | ❌ | Unique database identifier |
| `reviewText` | string | ❌ | The raw review text |
| `label` | enum | ✅ | Assigned label: `POSITIVE` or `NEGATIVE` |
| `labelSource` | enum | ✅ | `SEED` (model-confident) or `CLAUDE` (oracle-labelled) |
| `confidenceScore` | number | ❌ | Model confidence between 0.0 and 1.0 |
| `uncertain` | boolean | ❌ | `true` if confidence was below threshold and Claude was consulted |
| `createdAt` | datetime | ❌ | System-managed |
| `updatedAt` | datetime | ❌ | System-managed |

#### `TrainingResponse`
Returned by `POST /api/model/train`.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `trainedAt` | datetime | ❌ | When the training run completed |
| `samplesUsed` | integer | ❌ | Total labelled samples used |
| `positiveCount` | integer | ❌ | POSITIVE samples in training set |
| `negativeCount` | integer | ❌ | NEGATIVE samples in training set |
| `accuracyScore` | number | ❌ | Accuracy on hold-out set (0.0–1.0) |
| `precisionScore` | number | ❌ | Precision on hold-out set (0.0–1.0) |
| `recallScore` | number | ❌ | Recall on hold-out set (0.0–1.0) |
| `modelSavedToDisk` | boolean | ❌ | Whether the model was persisted successfully |
| `modelStoragePath` | string | ✅ | Path where the model was saved. `null` if save failed. |
| `note` | string | ✅ | The audit note from the original request |

#### `ModelStatsResponse`
Returned by `GET /api/model/stats`. Combines live database counts with historical training metrics.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `trained` | boolean | ❌ | Whether a trained model is available |
| `lastTrainedAt` | datetime | ✅ | Timestamp of last training run. `null` if never trained. |
| `samplesUsedInLastRun` | integer | ❌ | Samples used in last training run. Zero if untrained. |
| `totalLabelled` | integer | ❌ | Total labelled samples in the database right now |
| `positiveCount` | integer | ❌ | POSITIVE labelled samples |
| `negativeCount` | integer | ❌ | NEGATIVE labelled samples |
| `seedLabelledCount` | integer | ❌ | Samples labelled from seed data |
| `manualLabelledCount` | integer | ❌ | Samples labelled manually via the API |
| `claudeLabelledCount` | integer | ❌ | Samples labelled by the Claude AI oracle |
| `accuracyLastRun` | number | ❌ | Accuracy from last training run. Zero if untrained. |
| `retrainBatchSize` | integer | ❌ | Configured Claude-label count that triggers a retrain |
| `retrainBatchProgress` | integer | ❌ | Claude labels accumulated since last retrain |

#### `ActiveLearningStatusResponse`
Returned by `GET /api/model/active-learning-status`.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `cycleActive` | boolean | ❌ | `true` if the model is trained and the cycle is operational |
| `totalRetrainingRuns` | integer | ❌ | Total automatic retraining runs since startup |
| `lastRetrainedAt` | datetime | ✅ | Timestamp of most recent retrain. `null` if never. |
| `claudeLabelledSinceLastRetrain` | integer | ❌ | New oracle labels since last retrain. Resets after each retrain. |
| `retrainBatchSize` | integer | ❌ | Configured batch size threshold |
| `progressPercent` | integer | ❌ | Progress towards next retrain (0–100) |
| `totalUnlabelled` | integer | ❌ | Reviews currently awaiting a label |
| `modelStoragePath` | string | ❌ | Configured path for the serialised model file |
| `modelFileExists` | boolean | ❌ | Whether the model file exists on disk |

#### `ApiErrorResponse`
Returned by all endpoints on error. Always the same four-field envelope.

| Field | Type | Description |
|-------|------|-------------|
| `httpStatus` | integer | The HTTP status code (e.g. `400`, `404`, `409`, `502`) |
| `httpStatusText` | string | The HTTP status description (e.g. `"Bad Request"`) |
| `errorCode` | string | Machine-readable error identifier (see table below) |
| `message` | string | Human-readable description safe to display to end users |

## ⚠️ Error Codes Reference

Every error response carries a machine-readable `errorCode` field. The complete set:

| Error Code | HTTP Status | When It Occurs |
|------------|-------------|----------------|
| `VALIDATION_ERROR` | 400 | A request field failed bean validation (blank, too long, wrong format) |
| `INVALID_FIELD_VALUE` | 400 | A field value is syntactically valid but semantically incorrect |
| `MALFORMED_REQUEST` | 400 | The request body could not be parsed — invalid JSON or wrong content type |
| `REVIEW_NOT_FOUND` | 404 | No review sample exists for the given ID |
| `REVIEW_ALREADY_EXISTS` | 409 | A review with the same text already exists in the database |
| `MODEL_NOT_TRAINED` | 409 | A classification was requested but no trained model is available yet |
| `INSUFFICIENT_TRAINING_DATA` | 409 | A training run was requested but not enough labelled samples exist |
| `CLAUDE_API_UNAVAILABLE` | 502 | The outbound call to the Anthropic Claude API failed (network / timeout) |
| `CLAUDE_RESPONSE_INVALID` | 502 | Claude returned a response that could not be parsed into POSITIVE or NEGATIVE |
| `INTERNAL_ERROR` | 500 | An unexpected server-side error occurred |

## 🔄 Enumerations

### `SentimentLabel`
| Value | Meaning |
|-------|---------|
| `POSITIVE` | The review expresses a favourable sentiment |
| `NEGATIVE` | The review expresses an unfavourable sentiment |

### `LabelSource`
| Value | Meaning |
|-------|---------|
| `SEED` | Label was assigned automatically by the model when confidence was high |
| `MANUAL` | Label was assigned by a human operator via the API |
| `CLAUDE` | Label was assigned by the Claude AI oracle when the model was uncertain |
