# Documentation

This folder contains all supplementary documentation for the **Sentiment Active Learning** application — architecture diagrams, API specification, and API test collection.

The application source code lives in `sentiment-active-learning/`. Everything here is reference material intended to help developers, reviewers, and API consumers understand and interact with the system without reading the source.

---

## 📁 Contents

### [`plantUML-diagrams/`](./plantUML-diagrams/)
PlantUML source files (`.puml`) and rendered PNG exports documenting the system architecture and runtime behaviour.

| Diagram | What it shows |
|---------|---------------|
| Active Learning Cycle | Full sequence from review submission to automatic model retraining |
| Component Architecture | All layers, beans, and their runtime dependencies |
| Entity Model & Persistence Layer | JPA entity, enumerations, DAO interface, implementation, and repository |
| Startup Model Restoration Sequence | The three-branch decision tree executed at application startup |

See [`plantUML-diagrams/README.md`](./plantUML-diagrams/README.md) for diagram descriptions, regeneration instructions, and guidance on keeping diagrams in sync with the code.

---

### [`postman/`](./postman/)
A complete Postman collection for testing every API endpoint, together with environment files for local development and production.

| File | Description |
|------|-------------|
| `Sentiment-Active-Learning-API.postman_collection.json` | All endpoints, response examples, and automated test scripts |
| `SAL-Local-Dev.postman_environment.json` | Environment for `localhost:8080` with default credentials pre-filled |
| `SAL-Production.postman_environment.json` | Environment template for production deployments |

See [`postman/README.md`](./postman/README.md) for step-by-step import instructions, the recommended first-run workflow, and a troubleshooting guide — suitable for readers with little prior Postman experience.

---

### [`swagger/`](./swagger/)
The OpenAPI 3.1 specification generated by SpringDoc, together with a Swagger UI screenshot and a full reference guide covering every endpoint, schema, error code, and enumeration.

| File | Description |
|------|-------------|
| `api-docs.json` | The live OpenAPI 3.1 specification |
| `swagger-screenshot.png` | Screenshot of the Swagger UI showing all endpoints and schemas |

The interactive Swagger UI is available at `http://localhost:8080/swagger-ui/index.html` when the application is running.

See [`swagger/README.md`](./swagger/README.md) for the full endpoint and schema reference.
